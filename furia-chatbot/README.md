# Chatbot da FURIA (com IA)

Este projeto é um chatbot interativo inspirado na FURIA Esports, usando **Inteligência Artificial** via modelo **DeepSeek-R1** pela API do [OpenRouter](https://openrouter.ai/). Criado em **Python com Streamlit**, o chatbot responde como se fosse um integrante da FURIA: direto, simpático e com bom humor.

## Aviso legal
Este é um projeto educacional e independente, criado apenas para fins de aprendizado e demonstração.
Não possui qualquer vínculo oficial com a organização FURIA Esports.
Todo o conteúdo é fictício ou de domínio público, e não há finalidade comercial ou lucrativa.

## Acesse o chatbot online

## Tecnologias utilizadas

- Python
- Streamlit
- OpenRouter API (DeepSeek)
- `.env` com chave de API
- Deploy via Streamlit Cloud

## Funcionalidades

- Chat com histórico visível
- Botão para limpar conversa
- Mensagens interativas no estilo ChatGPT
- IA com personalidade gamer
