# FãFURIA – Cadastro de Fãs da FURIA

Este projeto simula uma página de **cadastro de fãs da FURIA**, com análise de perfil e sugestões personalizadas com base nas preferências do usuário. Desenvolvido em **Python com Streamlit**, é leve, interativo e pronto para uso.

## Aviso legal
Este é um projeto educacional e independente, criado apenas para fins de aprendizado e demonstração.
Não possui qualquer vínculo oficial com a organização FURIA Esports.
Todo o conteúdo é fictício ou de domínio público, e não há finalidade comercial ou lucrativa.

## Acesse o site online

[FãFURIA SITE](https://fanfuria-site-kjpkhwazdtbwsfdqeivesd.streamlit.app/)

## Objetivo

- Coletar dados fictícios de fãs
- Classificar o perfil (Hardcore, Casual, Fantasma)
- Reagir com mensagens personalizadas e divertidas
- Mostrar últimas notícias por modalidade

## Tecnologias utilizadas

- Python
- Streamlit
- Pandas

## Como rodar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
